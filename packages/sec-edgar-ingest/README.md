# sec-edgar-ingest 0.2.0

Native local SEC filing-index ingestion for CPython 3.14 on macOS arm64. The import package is `sec_edgar_ingest`; the console command is `sec-edgar-ingest`. This is the sole installable workspace member. Requests 2.34.2 and PyArrow 25.0.1 are pinned; the complete runtime graph is accepted from the lock and verified against installed distribution inventories.

The eleven commands are `discover`, `collect`, `transform`, `publish`, `backfill`, `daily`, `reconcile`, `candidates`, `approve`, `history`, and `rollback`. Each exposes `--help`. Workflow commands delegate through checked durable child results, immutable worksets and captured generations. Live execution requires the explicitly selected, non-editable release wheel environment. Local fixture mode is independent of local storage and uses explicit fixture-only controls.

Read [native setup](../../docs/runbooks/native-setup.md), [local ingestion](../../docs/runbooks/local-ingestion.md), [recovery](../../docs/runbooks/local-recovery.md), and [release upgrades](../../docs/runbooks/release-upgrades.md) for current commands. The repository-root `scripts/check-sec-edgar-ingest.sh` runs complete offline default checks after explicit artifact setup. There are no provider credentials, cloud execution identities, container images or schedules.

Publication readers call `capture_quarter` once then `read_quarter` using that exact capture. Never glob Parquet or interpret a pointer alone as completed workflow evidence. Whole-source quarantine is preserved for conflicting retained observations; approval gates never become success implicitly.
